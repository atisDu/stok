# stok

Penny-stock news aggregator + signal bot (StockTitan-style): ingests press releases and SEC filings,
scores them for real materiality (not just tone), confirms with price/volume, and sends tiered alerts.

Status: planning. See [PLAN.md](PLAN.md) for the feasibility assessment, architecture, and phased roadmap.

> Not financial advice. Signals are for research; nothing here should trade real money until the
> evaluation criteria in PLAN.md §5 are met.
